VRCinema

Privacy

VRCinema has no analytics or crash reporting, and it sends nothing to its author. There are no VRCinema accounts.

What stays on your computer

Settings, the queue, history and logs are kept in %LOCALAPPDATA%\VRCinema on Windows. Deleting that folder removes them.

What the program connects to

  • GitHub, to check for a new version and to download updates.
  • The download sites of its helper tools (FFmpeg, yt-dlp, Deno and cloudflared), during setup and when they are updated.
  • The sites of the videos you add, such as YouTube, to fetch those videos.
  • Cloudflare, only when the public link is on. The channel and the request page then pass through Cloudflare.

If you are a viewer

The channel and the request page are run by the person hosting them, on their own computer, not by the author of VRCinema. Their program receives your IP address when you connect. It uses the address to apply request limits and count viewers, and does not save it in its database. A nick, the videos you add and a key that identifies your browser are saved on the host's computer. Ask the host if you want these removed.

This website

This site uses no cookies, analytics or outside fonts. It is hosted on GitHub Pages, and GitHub may log visitors' IP addresses as described in the GitHub privacy statement.
